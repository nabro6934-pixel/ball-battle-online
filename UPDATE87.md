# v87 — Consistent mode training, objective scoreboard and inline replays

- Mode practice reuses the original Bot Arena settings cards, two-player setup layout, roster grid, participant presets, random placement and action footer. Existing 1v1/Arena tabs remain intact.
- Two-player training now runs on the original `battle` renderer/HUD. The original frame loop explicitly excludes training so the dedicated simulation never ticks twice or calls normal match/reward handling. Multiplayer training shares the actual original Arena paint function, health labels and impact sound coalescing, and uses its roster/HUD/winner presentation.
- Training starts and round transitions use the existing profile-card/countdown component with correct hero icons, powers and team/observer labels. Manual own ultimates, spectator mode, pause/speed/reset/edit, normal target HP and no real rewards remain.
- Six event modes have a large DOM scoreboard in online games, training and replays: control percentage per team, crown hold seconds/carrier, bounty team score/streak, relay round/wins, timed walls/alive count, and mirror health. Values derive directly from authoritative state; duplicate team member scores are not summed. Canvas text clutter is removed while world objectives remain.
- Removed the separate replay tab. Recent history rows now contain a replay button linked by exact match identity. Missing local recordings show a disabled button. Available recorded rounds play consecutively with a separate monotonic playback timeline, preserving original simulation timestamps and seek behavior. Storage retains three match groups within a 48 MB sampling budget, account separated.
- Legacy friend-royale states/history now share one stable replay ID rather than a mutable simulation seed at the end.

Validation: `npm run test:update87` includes presentation-value/identity/timeline/retention tests, all 18 DOM training launches, original setup/roster/countdown elements, native 1v1 single-clock behavior, visible 50% control HUD, multi-player winner/reset, inline replay seek and account separation, plus full prior backend, assets, claims, modes and balance regression suites. Local Chromium pixel rendering is unavailable, so these are DOM/canvas-API and rules checks rather than pixel verification.
